### References:

- When referring to `hybrid`, this means the command can be ran as a prefix, and slash command, and can be ran anywhere, including DMs and Group chats. (You do need to install the bot though.)
- When referring to `listeners`, this is referring to something the bot does in the background, such as a message event, or member event, this are not executable commands.
- When referring to `help module`, this is referring to a module that is used to display help commands.
- When referring to `cog`, this is referring to the modules which group commands, example being `moderation`.
- When referring to `groups`, this is referring to commands which can be invoked with a subcommand, such as `lore`, or `role`.
